# GitHub Issues & Milestones Creator Skill

## Метаданные

- **name**: `github-issues`
- **description**: создаёт GitHub Issues и milestones из файла плана. Использовать, когда есть готовый план с фазами и нужно создать бэклог на GitHub.

## Поведение скилла

Скилл принимает аргумент — путь к файлу плана (например, `docs/file-upload-plan.md`) — и на его основе создаёт соответствующие сущности в указанном репозитории GitHub.

### Порядок действий

1. **Прочитать файл плана**
   Скилл загружает и парсит указанный файл плана, извлекая:
   - Название фичи (заголовок)
   - Список фаз (номер, название, цель, задачи, критерий готовности)

2. **Проверить наличие GitHub CLI**
   Скилл проверяет, доступна ли команда `gh` в окружении. Если нет — сообщает об ошибке и останавливается.

3. **Определить репозиторий**
   Если репозиторий не передан явно через аргументы или не задан в переменных окружения (`GITHUB_REPO`), скилл запрашивает его у пользователя в формате `owner/repo`.

4. **Создать milestones**
   Для каждой фазы создаётся milestone с помощью команды:
   ```bash
   gh api repos/{owner}/{repo}/milestones --field title="<название фазы>"
   ```
